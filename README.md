# ⚔️ Blizz Nameplates+

**Blizz Nameplates+** enhances the original Blizzard nameplates for Vanilla WoW while keeping the classic look and feel.

🔹 Requires **SuperWoW**  
🔹 Works standalone  
🔹 Compatible with **ShaguTweaks**

---

## ✨ Features

- 🩸 Personal Debuff & CC Tracking
- ⏱️ Accurate Debuff Timers
- 🎯 Multi-Target Tracking
- 🚫 Resist / Miss Detection
- 🧹 Automatic removal of expired, dispelled or broken effects
- 🔮 Support for custom / Turtle WoW effects
- 🎨 Player Class Colors
- 📏 Adjustable Nameplate Scale
- 🔍 Adjustable Debuff Icon Size
- 🔥 Nameplate Castbars with Spell Icons
- 📊 Adjustable Castbar Height
- ⚡ Smooth Castbar Animation
- 🛡️ Optional Tank Mode
- ⚙️ In-Game Settings Menu
- 🔧 ShaguTweaks Compatibility

---

## ⚙️ Settings

Open the menu with:

`/bnp`

Available options:

- 📏 Nameplate Scale
- 🔍 Debuff Icon Size
- 📊 Castbar Height
- 🎨 Class Colors
- 🔥 Castbars
- 🛡️ Tank Mode

---

## 🔎 Missing Spells?

If a Debuff or CC is missing, use the spell and type:

`/bnp unknown`

📸 **Please take a screenshot of the output and include it in your report!**

Additional debug information:

`/bnp unknown verbose`

Clear collected data:

`/bnp unknown reset`

---

## 📦 Requirements

- 🎮 Vanilla WoW 1.12
- ⚡ SuperWoW

**ShaguTweaks is optional.**

If ShaguTweaks is detected, Blizz Nameplates+ automatically handles compatibility with overlapping nameplate features.
